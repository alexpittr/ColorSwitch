1)A fast-paced Unity arcade game inspired by the classic Color Switch concept.
Control the ball, switch through obstacles, and survive as long as possible by matching colors and timing your moves perfectly.
Gameplay

The player controls a bouncing ball that can only pass through obstacles matching its current color.

2)Rules
Tap / Click to jump
Pass through matching colors only
Touching a different color ends the game
Collect stars to increase your score
Reach the highest score possible

3)Built With
Unity
C#
Unity Physics System
Unity UI System
